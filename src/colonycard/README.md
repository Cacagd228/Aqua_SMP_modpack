# Colony Card (NeoForge 1.21.1)

Мод добавляет "карту колониста" — визуальную вкладку с профилем игрока на сервере,
собранную по присланной схеме.

## Что реализовано (по зонам схемы)

1. **Модель игрока** — как окошко в инвентаре, крутится за курсором.
2. **Имя колонизатора** — ник игрока.
3. **Дата прибытия** — дата первого захода на сервер (запоминается автоматически).
4. **Цель прибытия** — случайная цель из пула, выдаётся один раз при первом входе.
5. **Особые черты** — 3 случайные черты из пула в 10 черт, выдаются один раз при первом входе.
6. **Лояльность к короне** — полоса от 0 до 100, старт по центру (50), слева красный
   (низкая лояльность) через жёлтый к зелёному справа (высокая).
7. **Вклад в развитие Короны** — обычная полоса прогресса 0-100+.
8-10. **Именные награды** — строки с названием награды, серые пока заблокированы.
11-13. **Иконки наград** — розовые круги с предметом-иконкой, тускнеют пока заблокированы.

Сверху — 4 красные вкладки-заглушки (как в схеме), первая открывает карту колониста,
остальные три зарезервированы под будущий контент (рамка есть, содержимое можно
дописать позже).

## Управление

- Апостроф (`'`) по умолчанию открывает карту. Перебиндить можно в
  Настройки → Управление → Colony Card.

## Команды администратора (op-уровень 2)

```
/colonycard loyalty <игрок> set <0-100>
/colonycard loyalty <игрок> add <-100..100>
/colonycard contribution <игрок> set <0..>
/colonycard contribution <игрок> add <любое>
/colonycard reward <игрок> <1-6> unlock|lock
```

Награды 1-3 — верхние именные строки (зоны 8-10), награды 4-6 — иконки-кружки
(зоны 11-13). Дальше их можно связать с достижениями, квестами или порогом
лояльности/вклада — сейчас они переключаются только командой, логику выдачи
проще всего повесить в `ColonyCardCommands`/`ServerEvents`, вызывая
`player.setData(ModAttachments.COLONIST_DATA, data.withReward(index, true))`.

## Сборка

Нужны JDK 21 и интернет (гредл скачает NeoForge 21.1.240 и зависимости).

```
./gradlew build
```

Готовый .jar появится в `build/libs/`.

## Структура

```
src/main/java/com/colonizer/colonycard/
├── ColonyCardMod.java              — точка входа, регистрация payload/attachment
├── client/
│   ├── ColonistCardScreen.java     — сама вкладка (всё рисование по зонам 1-13)
│   ├── ClientColonistCache.java    — кэш данных игрока на клиенте
│   ├── ClientModEvents.java        — регистрация клавиши
│   └── ClientTickHandler.java      — открытие экрана по клавише
├── data/
│   ├── ColonistData.java           — модель данных (record + Codec)
│   ├── ColonistPools.java          — пулы черт/целей/наград
│   └── ModAttachments.java         — data attachment (хранение на сервере)
├── network/
│   └── SyncColonistDataPacket.java — S2C синхронизация данных
└── event/
    ├── ServerEvents.java           — генерация профиля при первом входе + синк
    └── ColonyCardCommands.java     — /colonycard команды
```

Изменить тексты (названия черт, целей, наград) — правь
`src/main/resources/assets/colonycard/lang/ru_ru.json` и `en_us.json`.
Изменить размеры/расположение зон — правь константы и координаты в
`ColonistCardScreen.java` (там всё прокомментировано по зонам 1-13).
